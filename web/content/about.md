# About

Hi — I'm the author of this site.

Replace this page by setting `AUTHOR_NAME`/`AUTHOR_BIO` and editing the About
content. You can override it without rebuilding by dropping an `about.md` into
your data directory (`$DATA_DIR/about.md`); otherwise this embedded default is
used.

This site is built with [aniicrite.dev](https://github.com/) — a small,
from-scratch blog engine in Go (server-side rendering + HTMX + SQLite). No
static site generator, no theme.
